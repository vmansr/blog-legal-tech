# Blog Profesional: Convergencia Legal & Ciberseguridad

Este proyecto es un blog personal desarrollado con HTML5 y CSS3 que refleja mi perfil híbrido como Abogado con 20 años de experiencia y estudiante de Ingeniería de Sistemas[cite: 1].

## 🎯 Objetivo
Documentar mi proceso de aprendizaje en el desarrollo web, laboratorios de ciberseguridad y la implementación de soluciones Legal Tech.

## 🛠️ Stack Tecnológico
- **HTML5:** Estructura semántica enfocada en accesibilidad y SEO.
- **CSS3:** Diseño responsivo utilizando Flexbox y CSS Grid.
- **Enfoque:** Privacidad desde el Diseño (Privacy by Design).

## 🚀 Contenido del Blog
- **Legal Tech:** Integración de normativa legal con automatización de software.
- **Ciberseguridad:** Documentación de herramientas de auditoría y hardening (Nmap, Wireshark, OSSEC).
